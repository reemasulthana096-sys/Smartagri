# Smart Agriculture Assistant 🎯

## Basic Details
**Team Name:** [TECHY TECH]

**Team Members:** [Member 1 -REEMA SULTHANA, MAMO COLLEGE], [Member 2 - ZAHWA T, MAMO COLLEGE]

**Hosted Project Link:** [https://reemasulthana096-sys.github.io/Smartagri/]

**Project Description:**  
A comprehensive web-based tool designed to assist farmers by providing detailed crop information (soil, fertilizer, pests, water) and an AI-powered chatbot for real-time agricultural queries.

**The Problem & Solution:**  
Farmers often lack accessible, consolidated information about specific crop needs and immediate expert advice. This app solves this by centralizing detailed crop data and leveraging AI to answer farming questions instantly, empowering farmers with data-driven insights.

## Technical Details
**Technologies Used:** HTML5, CSS3, JavaScript (Vanilla), Groq API (AI Integration)

### Features
- **Instant Crop Analysis:** Retrieve detailed soil, fertilizer, pest, and water requirements for various crops.
- **AI-Powered AgriBot:** Smart chatbot assistant for answering complex farming queries in real-time.
- **Visual Water Indicator:** Intuitive progress bar showing specific water needs for each crop.
- **Responsive Design:** Mobile-friendly interface ensuring accessibility for farmers on any device.
